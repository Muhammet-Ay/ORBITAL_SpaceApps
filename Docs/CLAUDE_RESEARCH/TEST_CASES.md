# ORBITAL: Test Cases (baseline v2.1)

Author: Claude, reconciled with Codex's acceptance cases. Date: 2026-11-14.
Generated by `python reference_model.py`. Do not edit numbers by hand; rerun the model.

How to use: implement the formulas in C++, load PART_CATALOG.json, build each design, compare.
Designs are in `reference_builds` in the catalog; each case's Setup line names the change.
Tolerances: delta-v within 0.5 m/s, TWR within 0.001, mass exact to 0.1 kg, cost exact,
energy and data within 1 %. BLOCK, RISK and WARN code lists must match exactly.
